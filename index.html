App Store chart rank tracker

See where your competitors sit in the App Store charts and how they moved. Paste one or more chart history responses below (a JSON object, or an array of them, or one object per line). Nothing leaves your browser.

Where to get the JSON

The input is the chart history response from PeekPanda, which keeps dated daily snapshots of the public Apple free, paid and grossing charts: GET /v1/charts/apps/{storeId}/history on the API, or the get_app tool with action chart_history over MCP. You need a PeekPanda account. See the chart history docs. Grossing is a position, not revenue.

A command-line version with CSV output and a Slack alert lives in the GitHub repo.
